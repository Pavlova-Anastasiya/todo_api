# Todo API (FastAPI)

Простой и эффективный RESTful API для управления списком задач (Todo), разработанный на **FastAPI** с использованием **Pydantic** для валидации данных. Проект создан в рамках изучения современного бэкенд-потока на Python.

## 🛠 Технологии

* **Python 3.13+**
* **FastAPI** — современный, быстрый веб-фреймворк для создания API.
* **Pydantic** — строгая типизация и валидация данных.
* **Uvicorn** — молниеносный ASGI-сервер.

---

## 🚀 Эндпоинты API

| Метод | Путь | Описание |
| :--- | :--- | :--- |
| `GET` | `/` | Приветственное сообщение / проверка работоспособности |
| `GET` | `/tasks` | Получить список всех задач |
| `POST` | `/tasks` | Создать новую задачу |
| `GET` | `/tasks/{task_id}` | Получить конкретную задачу по её ID |
| `PUT` | `/tasks/{task_id}` | Обновить существующую задачу по ID |
| `DELETE` | `/tasks/{task_id}` | Удалить задачу по ID |

## ⚙️ Установка и запуск локально

1. **Клонируй репозиторий:**
   ```bash
   git clone [https://github.com/Pavlova-Anastasiya/todo_api.git](https://github.com/Pavlova-Anastasiya/todo_api.git)
   cd todo_api
   
2. **Установи зависимости и настрой виртуальное окружение (рекомендуется использовать менеджер uv или стандартный venv):**
   ```bash
   uv sync

3. **Запусти сервер разработки:**
   ```bash
   uvicorn src.main:app --reload

4. Открой интерактивную документацию (Swagger UI):
После запуска перейди в браузере по адресу:
👉 http://127.0.0.1:8000/docs
